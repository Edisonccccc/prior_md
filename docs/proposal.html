How It Works

The AI reads and drafts. Code does all the math. You stay in charge.

AI

1 · Read & extract

Pulls drug, dose, frequency, dates, diagnoses from the documents — and must cite the exact sentence for every value. If something isn't documented, it says so instead of guessing.

Code

2 · Verify & calculate

Day supply, vial counts, and J-code units are computed by tested software, never by the AI — so quantities can't drift or be "creative."

You

3 · Review & submit

You get a worksheet: numbers, draft one-liner, and warnings (e.g., "order supports 14 days but request is 21"). Your corrections make the system smarter.

Quality control: every case you've solved correctly becomes a permanent automated test. Any future change to the system must pass every one of them before going live. Today: 20 code tests + 8 evaluation checks, all passing.
